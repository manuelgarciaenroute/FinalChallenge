# Coding Assistants Website

This project contains a simple multi-page company website for **Coding Assistants**, built with plain HTML, CSS, and JavaScript.

## Project Structure

- `src/html`: Main website pages
- `src/css`: Shared styling (`styles.css`)
- `src/js`: Shared client-side behavior (`main.js`)

## Website Description

The website presents Coding Assistants as a software support and engineering services company. It includes a consistent navigation bar, shared visual style, and small interactive behaviors such as active nav highlighting, dynamic footer year, and a contact form confirmation message.

## Main Pages

### 1. Home (`src/html/index.html`)
- Introduces the company and its value proposition.
- Highlights core service areas such as code acceleration, quality engineering, and automation.
- Includes a call-to-action button that links to the contact page.

### 2. About (`src/html/about.html`)
- Describes the company background and mission.
- Lists core values and working principles.

### 3. Clients (`src/html/clients.html`)
- Showcases example client profiles and collaboration outcomes.
- Demonstrates the variety of industries and project types served.

### 4. Contact (`src/html/contact.html`)
- Provides a basic contact form with name, email, and message fields.
- Uses JavaScript to handle form submission and show a confirmation message.

## Shared Assets

- `src/css/styles.css`: Controls layout, colors, typography, navigation, cards, grid sections, and form styling.
- `src/js/main.js`: Handles active navigation state, footer year rendering, and contact form submit feedback.
